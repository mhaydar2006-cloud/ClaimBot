# Data layer

This folder contains the prototype's static/synthetic data assets:

- `insuranceData.ts` — insurer, TPA, service, procedure and document labels/mappings.
- `sources.json` / `sources.ts` — authoritative-source registry and lookup helpers.
- `syntheticPolicies.ts` — five fictional policy/Table of Benefits profiles used for demo and regression testing.
- `claimDefaults.ts` — empty and synthetic MRI request builders.
- `mockData.ts` — synthetic dashboard/account/demo display data.

No production patient record is bundled. Policy profiles labeled synthetic are fictional and must not be represented as real insurer products.
